# Testing Strategy

## Testing Levels
- Unit Tests: Models, serializers, utilities
- Integration Tests: API endpoints, workflows
- Functional Tests: User flows
- Security Tests: Auth, permissions, audit
- Responsive Tests: UI on different screens

## Testing Tools
- Backend: Django TestCase, pytest (if used)
- Frontend: Vitest/Jest (as needed)

## Acceptance Criteria
All features must meet acceptance criteria defined in requirements-specification.md

## Definition of Done
Per dod-milestones.md - code reviewed, tested, documented, meets AC

## Test Evidence
All tests must be documented with evidence per project standards
