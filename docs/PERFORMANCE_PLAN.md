# Performance Plan

## Targets
- Responsive UI on mobile and desktop
- Reasonable API response times
- Efficient database queries (select_related/prefetch_related)

## Optimization
- Database indexing on foreign keys and slugs
- Pagination for list endpoints
- Image optimization (if used)
- Caching considered where appropriate

## Monitoring
- Basic performance checks during testing
- No premature optimization
