**How to monitor your project in practice**
I recommend using three connected management tools rather than trying to manage everything in a single document.

Use the Gantt schedule to track deadlines, dependencies and milestone completion.
Management registers
Use spreadsheets for the budget, risks, issues, changes and weekly progress reporting.

### 4. Your first weekly management report
Starting with Week 1, maintain a record like this:

| Metric | Planned | Actual |
| --- | --- | --- |
| Working hours | 12 | To be recorded |
| Tasks completed |  | To be recorded |
| Tasks delayed | 0 | To be recorded |
| Budget expenditure | ₦0 initially | To be recorded |
| Critical open issues | 0 initially | To be recorded |

Do not fill in actual results until the work has happened. This distinction between planned and actual performance is important evidence of your project management practice.
