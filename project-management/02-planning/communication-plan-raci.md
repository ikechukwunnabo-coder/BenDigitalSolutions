# Communication Plan & RACI Matrix

## 1. Communication Plan
| Communication | Frequency | Audience | Method | Purpose |
| --- | --- | --- | --- | --- |
| Daily work log | Daily | PM/PO (self) | Task board/notes | Track progress |
| Weekly status report | Weekly | PM/PO | Status report | Review progress, risks, issues |
| Sprint planning/review | Biweekly | PM/PO | Sprint board | Plan/review iterations |
| Risk review | Weekly | PM/PO | Risk register | Monitor risks |
| Change control review | As needed | PM/PO | Change log | Evaluate changes |
